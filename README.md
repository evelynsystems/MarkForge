MarkForge is a desktop application from Desert Rat Software designed to make creating and packaging projects simpler from one interface.

It combines Markdown editing, live preview, project management, image management, Reader Mode, HTML and PDF export, and application packaging into a single tool.

One of MarkForge’s major features is its AppImage Builder. It can take a Python project from a folder or ZIP, detect available startup files, build the project inside a portable Ubuntu environment, create the AppImage, and then launch test the finished application.

MarkForge also provides detailed build logs and identifies project errors when a build fails, helping pinpoint problems instead of simply reporting that the package could not be created.

MarkForge has already successfully packaged PromptPilot 4.0 into a working Linux AppImage.

More development is planned, including additional packaging and platform support.
